====================================
  momo-corn APK 极速打包流程
====================================

【项目位置】
  D:\APK\APK

【环境要求】
  - 系统默认 Java 是 JDK 8，但项目 Gradle 9.3.1 需要 JDK 17+
  - 使用 Android Studio 自带的 JDK 21（路径：D:\AndroidStudio\jbr）
  - Android SDK 路径：D:\AndroidStudio\Sdk

【极速打包方式（推荐）】

方法 A：使用项目一键极速打包脚本（PowerShell）
  直接在项目根目录运行：
    .\build-apk.ps1

  可选加速参数：
    .\build-apk.ps1 -Arch arm64-v8a     # 仅编译 64 位真机架构（极速模式，15~25 秒）
    .\build-apk.ps1 -InstallDeps        # 先 npm ci 再打包

方法 B：手动执行极速 Gradle 命令（PowerShell / Git Bash）
  1. 设置环境变量：
     $env:JAVA_HOME = "D:\AndroidStudio\jbr"
     $env:ANDROID_HOME = "D:\AndroidStudio\Sdk"
     $env:PATH = "$env:JAVA_HOME\bin;$env:PATH"
     cd "D:\APK\APK\android"

  2. 执行极速构建：
     .\gradlew.bat assembleRelease --daemon --build-cache --parallel -x lintVitalRelease

【核心加速原因】
  1. --daemon：启用常驻 Gradle 守护进程，免去每次 JVM 冷启动与 JIT 预热开销。
  2. --build-cache & --parallel：开启构建缓存与多任务并行执行，未变动的模块直接命中间隙缓存。
  3. -x lintVitalRelease：跳过打包期重复耗时 1~2 分钟的静态代码分析（代码检查请提前通过 npm run check 执行）。
  4. -PreactNativeArchitectures=arm64-v8a（可选）：真机调试时仅编译单一架构，无需耗时编译 x86/x86_64/v7a。

【输出产物】
  APK 路径：
    D:\APK\APK\android\app\build\outputs\apk\release\app-release.apk

  安装至连接设备：
    adb install -r "D:\APK\APK\android\app\build\outputs\apk\release\app-release.apk"

【常见问题】
  Q: 编译报错 "Unsupported class file major version"
  A: JAVA_HOME 没设对，确认指向 D:\AndroidStudio\jbr（JDK 21），不是系统默认的 JDK 8

  Q: 编译报错 SDK not found
  A: ANDROID_HOME 没设对，确认指向 D:\AndroidStudio\Sdk

【耗时参考】
  - 极速增量构建：约 30~50 秒
  - 单架构极速构建：约 15~25 秒
